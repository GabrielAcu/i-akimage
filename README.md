# IÑAKIMAGE — Boceto Web Oficial

Landing page diseñada a medida para **IÑAKIMAGE** (`@inakimage_`) a partir del relevamiento de su perfil de Instagram y TikTok. Lista para desplegar en **Vercel** con configuración cero.

## Características incluidas
- **Identidad visual fiel a la marca:** Estética broadcast oscura (`#08080A`), acentos carmesí (`#DC2626`) y tipografía `Cinzel` + `Plus Jakarta Sans` + `JetBrains Mono`.
- **4 pilares de negocio:** Venta de equipamiento audiovisual, Financiación para Iglesias y Empresas, Rental Low Cost y Producción/Streaming en vivo.
- **Catálogo interactivo con filtros** (`Todos`, `Venta`, `Rental Low Cost`, `Combos Streaming`) y botón directo a WhatsApp pre-completado con cada equipo.
- **Armador de consulta rápida:** El cliente elige su perfil (Iglesia, Empresa o Streaming/Show) y modalidad para enviar un mensaje armado a WhatsApp (`11 2829-2015`).
- **Social proof real:** Shows y producciones destacadas del perfil (`Ni Fu Ni Fa`, `La Juntada del Folclore`, `El Fogón de la Cumbia`, `La Ultimita Folk`, `Orquesta Kaluqueña`).

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue en Vercel

1. Subí esta carpeta a un repositorio de GitHub e importalo desde [vercel.com/new](https://vercel.com/new) (Vercel detecta Vite automáticamente gracias a `vercel.json`).
2. O desplegá directo desde la terminal:

```bash
npx vercel
```
